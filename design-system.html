Two typefaces. One accent. A fixed scale.

Everything on the site is built from what is on this page. If a value is not here, it does not go in a component. That is the whole discipline — the old site drifted because there was no such list.

Typography

Archivo for headings, Inter for reading

Down from six families. Archivo has weight and slight tension at large sizes; Inter is deliberately unremarkable at 16px, which is what body copy needs.

Your decision

Which image style are you making?

Razorpay uses both. They need different layouts, so pick one as the default before I build. Every placeholder on the site will carry exact dimensions and a description of what it should show.

Option A — photography 1200 × 800px, full bleed
A carer with a resident, a manager at a desk with a folder. Real, undramatic, no stock smiling.

Photography

Warmer. Sells the setting, not the software. Harder to get right — one wrong stock photo and the whole page reads as a brochure. Needs full-bleed space.

Option B — product screenshots 1000 × 700px, on a tinted panel
The actual capture screen, a completed record, a policy check showing what is missing.

Product screenshots

Proof rather than mood. Shows a sceptical manager the thing is real. Sits inside a framed panel, so the layout is tighter and it never looks like a brochure.

Applied — how it works

Staff speak

A voice note at the point of care. No typing on a shift.

It becomes the record

Structured fields — consent, medication, incidents, pain — not a paragraph.

It's checked before you file

Against the regulation it has to satisfy. Missing something? You find out now.

Enforced

What this system bans

Gradient backgrounds. The clearest tell of a generated page.
Three-equal-icon feature grids. Every template has one.
Stock illustration and 3D shapes. Nothing that could belong to any company.
A second accent colour. If it needs to stand out and green is taken, it doesn't.
Body text under 16px, or any spacing value off the scale.
"Audit-ready", "seamless", "elevate", "unlock", "AI-powered". Words no manager says aloud.
